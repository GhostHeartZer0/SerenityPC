## 1. How rebasing works (step‑by‑step)


*Git*:
1. Determines the commit where `feature` diverged from `main`.
2. Temporarily **saves** those commits (as “patches”).

5. If a patch conflicts with the new code, Git pauses and lets you resolve it *per commit*.
