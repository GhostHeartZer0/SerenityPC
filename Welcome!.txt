================================================================================
SERENITYPC - USER GUIDE & GETTING STARTED
================================================================================

Welcome to SerenityPC: a local-first, privacy-respecting intelligent desktop 
interface and multi-agent orchestration engine. Runs open-weight LLMs directly on 
consumer hardware with zero cloud telemetry, full offline capability, and multimodal 
ingestion.

--------------------------------------------------------------------------------
1. SYSTEM REQUIREMENTS
--------------------------------------------------------------------------------

Minimum:
  - OS: Windows 10/11 (64-bit)
  - CPU: 4 cores
  - RAM: 8 GB
  - GPU: 4 GB VRAM (NVIDIA recommended)
  - Storage: 8 GB free space

Recommended:
  - CPU: 8+ logical cores
  - RAM: 16–32 GB
  - GPU: 6–24 GB VRAM (NVIDIA CUDA Compute Capability sm_75+)
  - Storage: 20+ GB SSD space

Memory Formula:
  Total Usable Capacity ≈ (VRAM - OS/Display Overhead) + (RAM - System Overhead)

--------------------------------------------------------------------------------
2. QUICK START & SETUP
--------------------------------------------------------------------------------

Step 1: Check CUDA & Build Environment
  - Verify NVIDIA CUDA 12.6+ / 13.x is installed (Misc > CUDA installer if needed).
  - Ensure Microsoft Visual C++ Build Tools (MSVC 2019/2022) are installed.

Step 2: Install Environment
  - Run setup:
      python SETUPfile.py
    (Developers can run 'python setup.py' for manual component inspection).

Step 3: Create Desktop Shortcut (Optional)
  - Generate launcher:
      python System/shortcuts.py

Step 4: Launch SerenityPC
  - Double-click the desktop shortcut, run 'run.bat', or execute:
      python main.py

--------------------------------------------------------------------------------
3. UI NAVIGATION & WORKFLOW
--------------------------------------------------------------------------------

1. Set Up Models:
   - Click Settings (gear icon, top-left).
   - Assign GGUF model paths to respective persona levels or engines.

2. Configure Parameters & Templates:
   - Choose a preset template or manually tune inference parameters.
   - In the Templating Engine: click 'Write', select target engine slot (e.g. Gemma-4).
   - Use 'Modify' to view and inspect templates.

3. Configure Layers (GPU Offloading):
   - 'Layers' dictates how many transformer layers offload to VRAM.
   - Set to maximum (e.g. 99 or -1) to fit entire model in VRAM for lowest latency.
   - Lower layer count if system encounters shared VRAM spills or OOM errors.

4. Select Persona & Chat:
   - Slide persona trackbar to desired level (Lvl 1 Spark, Lvl 2 Serenity, etc.).
   - Type prompt in the chat input at any time.
   - Click 'Begin!' or press Enter to load weights and begin inference.
   - 'Begin!' toggles to 'Offload' once active. Click 'Offload' to free VRAM/RAM.
   - Click 'Halt' at any time to abort mid-stream.

6. PARAMETERS & RESPONSE TUNING
--------------------------------------------------------------------------------

- Batch Size:
    Chunk size evaluated simultaneously (256, 512, 1024, 2048). Impacts peak memory.

- Temperature (Temp):
    Randomness control.
    0.0 = Deterministic/exact. Low (0.1–0.4) = Factual, code. High (0.7–1.0+) = Creative.

- Top-P (Nucleus Sampling):
    Cumulative probability cutoff (0.0–1.0). Only tokens within top P% considered.

- Min-P:
    Dynamic cutoff scaling against top token probability. Cuts low-probability noise.

- Top-K:
    Limits candidate pool to the K most probable next tokens.

- Repetition Penalty / Frequency Penalty:
    Penalizes repeated tokens/phrases to prevent degenerative output loops.

--------------------------------------------------------------------------------
7. ADVANCED ENGINE FEATURES
--------------------------------------------------------------------------------

- Deep Cook:
    Iterative reasoning pipeline.
    - One-Shot: Runs deep cook on the immediate prompt via the adjacent button.
    - Toggle Mode: Locks deep cook active for continuous reasoning cycles.

- Global KV Cache:
    - Manages Key-Value tensor quantization/compression to save VRAM on long contexts.
    - Allows split KV cache with Flash Attention (eg. Q8_0, Q4_0)

- Multimodal & Vision:
    - Select projector (.mmproj) matching your vision model.
    - Sub-chunk size controls frame ingestion density for video inference.
    - Use '+' button next to level slider to attach images, audio, or documents.
    Use 'Clean' to clear cached media from memory.

- DMN (Pulse):
    Default Mode Network background cycle. Reflects on recent conversational 
    history into prime.chronicles.txt to maintain long-term contextual continuity.

- Benchmarks:
    Performance and diagnostic utilities located in System/tests/benchmarks.
