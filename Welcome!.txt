=====================================================
SerenityPC Legacy v1.7.0 - Portable Quick Start
=====================================================

1. Keep this executable in its own dedicated folder.
2. Ensure there is a "Models" folder in the same directory:
      SerenityPC\
      ├── SerenityPC Legacy v1.7.0.exe
      └── Models\
           └── your_model.gguf
3. Double-click "SerenityPC Legacy v1.7.0.exe" to launch.
4. In Settings:
   - Select your model for the desired Level.
   - For older 4GB-6GB cards, set context (ctx) to 4096 or 8192.
   - Click "Save & Apply".

Requirements:
- NVIDIA GPU with modern driver (version 525 or newer).
- Visual C++ 2015-2022 Redistributable (x64).
- No Python or CUDA toolkit installation required.
