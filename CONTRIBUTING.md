# Contributing to SerenityPC

Welcome to my project! If you have any issues or suggestions please feel free to make an issue or suggest changes. All PRs are welcome, but I reccomend checking out one of SerenityPC's branches, those are free to do whatever with. I periodically update them from main whenever I get to a stable point. Feel free to fork, clone, edit, experiment with, etc. See TODO.txt and ISSUES&TODO.md for more information.
---

## How to Contribute

### 1. Fork the Repository
Fork this repository to your own GitHub account and clone it locally:
```bash
git clone https://github.com/YOUR_USERNAME/SerenityPC.git
```

### 2. Create a Feature Branch
Create a branch for your proposed changes:
```bash
git checkout -b feature/your-feature-name
```

### 3. Implement & Test
- Run `setup.py` to configure the environment.
- Verify that your changes run correctly in the GUI (`main.py`) or context.
- Keep your changes focused and clean.

### 4. Open a Pull Request
- Push your branch to your fork.
- Open a Pull Request (PR) targeting the `main` branch of `GhostHeartZer0/SerenityPC`.
- Provide a brief description of what your changes accomplish.

## Code Review Process
- No changes are merged automatically.
- All submissions require review and approval by the maintainer.
- Review feedback will be discussed in the pull request thread.
